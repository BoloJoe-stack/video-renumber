# 视频随机编号

Windows 桌面工具，用于批量处理以「人名（序号）」命名的视频文件：统一命名，或打乱顺序后重新编号。

## 功能

- **统一命名**：将所选文件夹顶层的全部视频命名为 `人名（序号）`，人名由界面输入。
- **随机编号**：打乱视频顺序后按新顺序重新编号，人名保持不变。
- **起始序号**：上述两项操作均可指定第一个序号，取值范围为 0 或正整数。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 免安装：从发布页下载 `视频随机编号.exe` 后直接运行，无需安装 Python。

## 使用

1. 运行 `视频随机编号.exe`。
2. 点击「添加文件夹」选择视频目录。路径保存在列表中，可重复使用；选中后点击「删除」仅从列表移除，不删除磁盘文件。
3. 在「人名」中填写人名（按文件夹分别记忆），在「起始序号」中填写第一个编号（默认 1）。
4. 点击「统一命名」或「开始随机编号」。
5. 结果不符合预期时，点击「撤销上次」恢复操作前的文件名。

## 规则

### 统一命名

- 处理范围为所选文件夹顶层的视频文件；子文件夹与非视频文件不参与处理。
- 目标格式为 `人名（序号）`，括号为全角，扩展名保持原样。
- 序号按当前文件名的自然顺序分配，即 `2` 位于 `10` 之前。
- 已符合目标格式的文件保持不变；重复执行结果一致。

### 随机编号

- 处理范围为符合 `人名(序号)` 格式的顶层视频；其余视频保持原样。
- 人名为原文件名中括号之前的内容，随机过程中不改变。
- 随机策略：重复洗牌，取第一份「原本相邻的视频在新顺序中均不相邻」的结果；无法完全错开时，取相邻对数最少的结果。
- 相邻判定依据原文件名的自然顺序与新编号的连续关系；首尾不视为相邻。
- 实测（2026-10-30，每个规模 50 次）：文件数为 4 至 1000 时，零残留相邻对的比例为 100%；文件数为 3 时最少残留 1 对，属数学下限。1000 个文件的单次计算耗时约 2 毫秒。

### 起始序号

- 统一命名与随机编号均从该值开始编号。
- 原编号位宽统一时沿用补零（如 `01` 至 `12`）；位宽混用时按自然编号，不补零。

## 安全机制

- **两阶段重命名**：先将文件改为随机临时名，再改为目标名，避免目标名与现有文件互相覆盖。
- **失败回滚**：任一步骤失败时按相反顺序恢复原文件名。
- **结果校验**：重命名完成后逐个确认目标文件存在，校验通过才报告成功。
- **撤销记录**：每次成功后在 `%APPDATA%\VideoRenumber\history\` 保存新旧文件名对照，供「撤销上次」使用。

## 数据与网络

- 配置保存在 `%APPDATA%\VideoRenumber\config.json`，内容包括文件夹列表、各文件夹的人名与起始序号。
- 程序不联网，不上传任何文件。

## 已知限制

- 仅支持 Windows 64 位系统。
- 仅处理所选文件夹的顶层文件，不递归子目录。
- 视频扩展名白名单：mp4、mov、avi、mkv、wmv、flv、m4v、webm、mpg、mpeg、ts、mts、m2ts、3gp、rmvb、rm。
